使い方マニュアル

ショーの音楽を、リモコン1つで流すためのアプリです。画面には操作に必要なものだけを置き、説明はここにまとめています。画像は実際の画面です（曲名やフェードの数字はサンプル）。

1. 本番前の準備

  1. オンラインで開く。 最初の1回はネットにつないでアプリを開きます。画面をオフラインで使えるように保存します。
  2. 音源を取り込む。 「曲・フェード設定」で音源を追加します（くわしくは6. セットリストと音源の管理）。
  3. 保存する。 「設定を保存する」を押します。
  4. 本番画面で状態を見る。 下の画像の3つの印と帯が ✓ になっていれば準備完了です。
  5. ホーム画面に追加する。 iPhone：通常のSafariで開く → 共有 → 「ホーム画面に追加」。Mac：Safariは「ファイル → Dockに追加」、Chromeは「アプリとしてインストール」。起動時に、iPhone向けの再生方式が自動で選ばれます。
  6. 機内モードで通し確認する。 手順は7. オフライン・機内モードの確認。
印意味
音源・設定保存取り込んだ音源と設定が、この端末に保存されている
画面のオフライン保存アプリの画面がオフライン用に保存されている
GO準備GOを押して、リモコンの準備ができている

帯に出る主なメッセージ：「画面をオフライン用に保存中（最初はネット接続が必要）」はオンラインのまま少し待つ。「音源が見つかりません。再取り込みしてください」は音源を取り込み直す。「未確認の音源があります」は、音源チェックを押す。

注意：通常のブラウザと、ホーム画面に追加したアプリは、保存領域が別になる場合があります。追加したあとのアプリで音源を取り込み、オフライン準備を確認してください。

GO（アプリを開くたびに最初に1回）

GOを押すと、音を出さずに音声とリモコンの準備をします。アプリを開くたびに、最初に1回押してください。「GO · 準備済み」と出れば準備完了で、押し直してもかまいません。電話や他のアプリの音で中断されたときは、いったん停止してGOを押し直します。

本番前に、実際に使うスピーカーと接続で、音量・出力先とリモコンの動きを確認してください。

3. リモコンの操作

基準にしているリモコンは、ELECOMのJC-VRR04BKです。他の機種は、実際に試して確認してください。

ボタン操作
右今の曲を、その曲の終了設定で終わらせます。曲送りが「手動」なら、1回目で終了して無音で待機、2回目で次の曲が始まります。「クロス」なら1回で終了して、そのまま次の曲を始めます。終了フェードの最中にもう一度右を押すと、すぐ終了して次の曲を始めます
左1回目：今の曲の頭に戻ります。再生中なら再生を続け、一時停止中・待機中は止めたままです。続けて左を押すと前の曲の頭。時間では解除されません（曲が進んでも、次の左は前の曲です）。右・中央・停止を押すと「次の左は前の曲」の状態は解除されます。最初の曲より前には戻りません
中央位置を保ったまま一時停止、もう一度で再開。フェード中は、音量とフェードも止まり、残りの秒数から再開します。無音待機中の中央は待機のままです（次の曲は右）
上・下端末の音量を上げ下げします。フェードとは別です

リモコンから再生・一時停止のどちらが届いても、中央の切り替えとして扱います。連打した操作は捨てず、順番に処理します。

曲が最後まで自然に終わったときは、止まって「右を押すまで次曲は鳴りません」と出ます。例外は、設定の「完パケ」「繰り返し」を入れた曲です。最後の曲の次に、先頭へは戻りません。

4. 曲ごとの設定

「曲・フェード設定」で、曲ごとに設定します。iPhoneでは、曲ごとのカードを「∨」で開閉できます（最初は今の曲だけが開いています）。Macでは、すべて開いたままです。「カット｜フェード」「手動｜クロス」の切り替えは、選ばれている側が青緑で表示されます。選びたい側の文字（四角）を、iPhoneは1回タップ、Macは1回クリックすると、その側が選ばれます（選ばれている側を押しても変わりません）。

開始方法・終了方法（カット／フェード）

  • 開始方法は、その曲が始まるとき。終了方法は、その曲を右で終わらせるときの設定です。
  • 「フェード」にすると秒数の欄が出ます。スライダーは0.1秒刻みで、10秒より長いときは数字を直接入力します。フェードを選んだ曲は、秒数を入力しないと保存できません。
  • 「カット」に戻しても、入れた秒数は残ります。初期設定は、開始・終了ともカット、曲送りはクロスです（新しく取り込んだ曲）。すでに保存してある曲の設定は変わりません。

曲送り（手動／クロス）

  • 手動：右1回で音を消して待機、もう1回で次の曲を開始。
  • クロス：右1回で、終了したあと次の曲を自動で開始。各曲の終了・開始の秒数を使います。音を重ねる本来のクロスフェードではなく、順番に切り替わります。

曲送りは今終わる曲の設定、開始方法は次に始まる曲の設定が使われます。組み合わせは次の8通りです。

今の曲の終了曲送り次の曲の開始右を押すと
カット手動カット1回で終了・待機、2回目で即開始
カット手動フェード1回で終了・待機、2回目で次曲の秒数をかけて開始
フェード手動カット1回で秒数をかけて終了・待機、2回目で即開始
フェード手動フェード1回で秒数をかけて終了・待機、2回目で次曲の秒数をかけて開始
カットクロスカット1回で即終了→次曲を即開始
カットクロスフェード1回で即終了→次曲を秒数をかけて開始
フェードクロスカット1回で秒数をかけて終了→次曲を即開始
フェードクロスフェード1回で秒数をかけて終了→次曲を秒数をかけて開始

流し切ったら（完パケ／繰り返し）

  • 完パケ：曲を最後まで流し、そのまま次の曲へ進みます。次の曲の始まり方は、次の曲の開始設定（カット／フェード）に従います。最後の曲では進まず止まります。
  • 繰り返し：曲を最後まで流したら、同じ曲を頭から流し直します。頭の始まり方は、その曲の開始設定に従います。トークが長引いたときに使えます。準備した曲があっても繰り返しが優先で、次の曲へは右で進みます。
  • 2つは同時にONにできません（片方をONにすると、もう片方はOFFになります）。両方OFFなら、最後まで流れて止まります。
  • 途中で右を押したときは、完パケ・繰り返しでも、その曲の終了設定（カット／フェード）に従って次の曲へ進みます。曲の設定は変わりません。
  • 右を押して終了フェードの最中に曲が終わった場合や、停止・左・設定画面を開いたときは、自動では進みません。

5. 次に流す曲を準備する

  • セットリストの曲をタップすると、「次に開始する曲」として準備されます。今の音は止まりません。タップしても、その曲が再生・一時停止されることはありません。
  • 準備した曲は、次の2つで始められます。「選んだ曲を再生 →」を押す（今の曲を止めて、その曲の開始設定で始まります）。または、リモコンの右（通常の次の曲より優先して始まります。手動は2回、クロスは1回）。
  • 「選択を解除」か「停止して曲頭へ」で、準備を取り消せます。
  • 「保存済み音源をチェック」は、すべての曲の存在と情報を確認します（全曲の通し再生や、破損の完全な検査ではありません）。

6. セットリストと音源の管理

セットリストの切り替え・新規・複製・削除

  • 「＋ 新規」「複製」（音源は再利用されます）、「削除」（確認が出ます）。個数に上限はありません。本番中（再生中・一時停止中）は、操作できません。
  • リスト名は「曲・フェード設定」の「セットリスト名」で変更します。

音源の取り込み

  • iPhone：「＋ 音源を追加」から「ファイル」で複数選択。Mac：Finderなどからまとめて枠へドラッグ＆ドロップ（枠の外へ落としても、画面は切り替わりません）。
  • 取り込んだ音源はこの端末の中だけに保存され、アップロードされません。読み込めないファイルは、除外されて表示されます。
  • 同じ内容の音源は重複して保存されません。他のリストで使った音源は、「保存済み音源を追加」で再利用できます。
  • Apple Musicのライブラリやサブスクの曲を直接取り込むことはできません。権利のある音声ファイルを用意してください。

曲順・曲名・削除

  • 曲名は、各曲のカードの名前欄で変えられます。「この曲を削除」で曲をリストから外します。
  • 曲を追加・削除・並べ替えるのは、音を止めた設定画面で行います。保存すると、次回もこの順番になります。

保存と、設定画面の動き

  • 「設定を保存する」：端末に保存します。保存が終わるまでは「保存済み」にならず、未保存のときは未保存と表示されます。
  • 「保存して本番画面へ戻る」「保存せず本番画面でテスト」。
  • 設定画面を開くと、音を止めて今の曲と位置を保持します。フェードの途中だったときは、そのフェードは終了します。戻っても自動では再生されません。戻って中央（リモコン）を押すと、保持した位置から、変更後の開始方法で再生されます。
  • 設定が不正（たとえばフェードの秒数が空）のときは、保存・開始前に知らせます。

7. オフライン・機内モードの確認

  1. ネットにつないだ状態で、ホーム画面のアプリを開く。
  2. 本番画面の上のほうに「オフライン準備OK・音源と設定は端末保存済み」と出ているか確認（準備が整っていない間は、3つの準備の印も出ます）。
  3. 機内モードにして、Bluetoothだけオンに戻す。
  4. アプリを完全に閉じて、開き直す。
  5. GOを押して、リモコンの中央・左右・音量を試す。
  6. 実際の会場と同じスピーカー・接続で、音が出ることも確認する。

機内モードのままだと、新しい版には更新されません。更新は、オンラインのときに反映されます。

保存データについて：音源と設定は、このブラウザ／ホーム画面アプリの保存領域に入っています。Safariの「履歴とWebサイトデータを消去」、端末の空き容量不足によるOSの整理、プライベートブラウズでは、消えることがあります。また、アプリのURLが変わると保存領域が別になるため、取り込み直しになります。元の音源ファイルは、別に保管してください。

  • OSのアップデート、Bluetooth機器、音響の接続を変えたときは、本番前に必ず確認してください。

9. プレイリスト共有（ZIPで書き出し・読み込み）

作ったプレイリストを、音源・曲順・フェードなどの設定ごと、1つのZIPにまとめて、別の端末へ渡したり、バックアップしたりできます。画面の「プレイリスト共有」から使います（本番中は、再生を止めてから開いてください）。

書き出す（Macなど）

  1. 「プレイリスト共有」を開き、書き出すプレイリストを選ぶ。
  2. 「ZIPで書き出す」を押す。進み具合が表示され、「プレイリスト名.zip」が保存されます（Macはダウンロードフォルダ）。

ZIPには、プレイリスト名、すべての音源ファイル、曲順、各曲のフェード・カットの設定と秒数、曲送り（手動／クロス）、完パケ・繰り返しの設定が入ります。サーバーには何も送られません（ネットがなくても書き出せます）。

読み込む（Mac・iPhone）

  • Mac：ZIPをドロップ枠にドラッグ＆ドロップ、または「ZIPから読み込む」でファイルを選ぶ。
  • iPhone：MacからAirDropなどでZIPを送り、「ファイル」アプリに保存する。アプリの「ZIPから読み込む」を押し、そのZIPを選ぶ。

読み込むと、新しいプレイリストとして追加されます（今あるプレイリストは消えず、上書きもされません。同じ名前でも別のプレイリストになります）。完了すると、曲数が表示されます。音源は端末の中に保存され、以後はネットやMacがなくても再生できます。

バックアップとして使う：プレイリストを仕上げたら、ZIPで書き出して、別の場所（クラウド、USBメモリなど）にも保管してください。アプリのデータが消えたときは、そのZIPを読み込めば、音源と設定ごと元に戻ります。
エラーのとき：ZIPが壊れている、音源が足りない、設定が合わないなどの場合は、理由を表示して読み込みを中止します。中途半端なプレイリストは作られず、今のプレイリストにも影響しません。ZIPを展開・編集すると読み込めなくなることがあるので、そのまま使ってください。

iPhoneの保存容量が足りないときは、「端末の保存容量が足りません」と表示されます。大きなZIPは、読み込みに時間がかかります。進み具合の表示が終わるまで、画面を閉じないでください。
